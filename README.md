## 📦 Download

You can find available builds in the **Releases** section of this GitHub repository.

Download the required files from the same release to ensure that you have a matching version.

### ⚠️ Required Application Files

GhostFrogOpTool requires both of the following files:

- `GhostFrog.exe` — Main application executable.
- `GhostFrog.rs` — Required accompanying file.

**Both files must be present in the same folder for the application to run correctly.**

If `GhostFrog.rs` is missing, the application may fail to start.

Do not delete or rename the accompanying file.

## ▶️ Installation and Startup

Follow these steps to run GhostFrogOpTool:

1. Open the GitHub Releases section.
2. Download `GhostFrog.exe`.
3. Download `GhostFrog.rs` from the same release.
4. Create a folder for GhostFrogOpTool on your computer.
5. Place both files in that folder.
6. Make sure both files are from the same release.
7. Double-click `GhostFrog.exe` to launch the application.

### Important

Do not separate the executable from its required accompanying file.

Keep the original filenames and folder structure unchanged unless future documentation specifies otherwise.
